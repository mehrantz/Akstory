# عکستوری | AksTory

نسخه نمایشی فارسی و راست‌چین وب‌سایت عکستوری برای تبدیل عکس‌های موبایل به کتاب عکس شخصی.

## اجرا در Cursor

1. فایل ZIP را از حالت فشرده خارج کنید.
2. پوشه اصلی پروژه را در Cursor باز کنید.
3. ترمینال Cursor را باز کنید و اجرا کنید:

```bash
npm install
npm run dev
```

4. آدرسی که در ترمینال نمایش داده می‌شود را در مرورگر باز کنید. معمولاً:

```text
http://localhost:5173
```

## بررسی نسخه نهایی

```bash
npm run lint
npm run build
```

## وضعیت امکانات

- زبان فارسی و راست‌چین: فعال
- طراحی واکنش‌گرا: فعال
- فیلتر قالب‌ها: فعال
- مسیر نمایشی ساخت کتاب: فعال
- پرسش‌های بازشونده: فعال
- بارگذاری و ذخیره واقعی عکس: مرحله بعد
- پرداخت و ثبت سفارش واقعی: مرحله بعد
- پنل مدیریت و چاپخانه: مرحله بعد

## پرامپت کوتاه برای Cursor

```text
این پروژه نسخه نمایشی فارسی استارتاپ عکستوری است. ابتدا README-FA.md و ساختار پروژه را بررسی کن. سپس npm install و npm run dev را اجرا کن. معماری، جهت RTL، متن‌های فارسی و هویت بصری فعلی را حفظ کن. بدون تأیید من وابستگی‌ها یا ساختار پروژه را عوض نکن. اگر خطایی وجود داشت، علت را پیدا و با کمترین تغییر اصلاح کن و در پایان npm run lint و npm run build را اجرا کن.
```
